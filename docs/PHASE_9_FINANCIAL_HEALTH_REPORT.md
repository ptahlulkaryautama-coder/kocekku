# SAKKU — PHASE 9: FINANCIAL HEALTH PAGE

## 1. Objective

Build a production-quality Financial Health page with a composite health score, individual metric breakdowns, and deterministic next-best-actions.

---

## 2. Architecture

### Composite Health Score (0–100)

| Dimension | Max Points | Thresholds |
|-----------|-----------|------------|
| Savings Rate | 40 | ≥20% → 40, ≥10% → 25, ≥5% → 10, else 0 |
| Emergency Fund | 35 | ≥6mo → 35, ≥3mo → 20, ≥1mo → 8, else 0 |
| Debt Burden | 25 | ≤10% → 25, ≤20% → 18, ≤35% → 8, else 0 |

Score labels:
- 80–100: Excellent
- 60–79: Good
- 40–59: Fair
- 0–39: Poor

### Metric Breakdown

Five key numbers displayed:
- Liquid Assets (from `calculateAvailableCash`)
- Monthly Expenses (from `calculateMonthlyExpenses`)
- Monthly Income (from `calculateMonthlyIncome`)
- Debt Payments (derived from `calculateDebtBurden.ratio × income`)
- Net Worth (from `calculateNetWorth`)

### Next Best Actions

Generated by `generateNextBestActions()` — deterministic, rule-based, no AI.

Rules:
1. Emergency fund < 3 months → HIGH priority
2. Savings rate < 10% → HIGH priority
3. Debt burden > 35% → HIGH priority
4. Budget overruns → MEDIUM priority
5. All healthy → LOW priority (suggest investing surplus)

Max 4 actions displayed.
